Termux · arm32 build

kincode

Lightweight terminal coding agent — one-line install for Termux.

Install

curl -fsSL https://USERNAME.github.io/REPO/install.sh | bash

Run — DeepSeek

kincode -provider openai \
  -endpoint https://api.deepseek.com/v1 \
  -api-key sk-xxxx -model deepseek-chat

Run — Gemini

kincode -provider openai \
  -endpoint https://generativelanguage.googleapis.com/v1beta/openai \
  -api-key AIza-xxxx -model gemini-2.5-flash

Notes

  • Custom arm32 build — no runtime deps, single static binary.
  • Binary is fetched from Google Drive on first install; script verifies it's a real ELF before installing.
  • Re-run the install command anytime to redownload/update.
Replace USERNAME/REPO above with your GitHub Pages path once pushed.
